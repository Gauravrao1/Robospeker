        🤖 RoboSpeaker

[ DESCRIPTION ]
RoboSpeaker is a terminal-based Python program
that converts text into speech using pyttsx3.

--------------------------------

[ REQUIREMENTS ]
- Python 3.x
- pyttsx3 library

--------------------------------

[ INSTALLATION ]

$ pip install pyttsx3

--------------------------------

[ RUN PROGRAM ]

$ python robospeaker.py

--------------------------------

[ TERMINAL DEMO ]

$ python robospeaker.py

Welcome to RoboSpeaker created by Gaurav & Ikbal

Enter what you want to speak:
> Hello Gaurav
(Speaking...)

Enter what you want to speak:
> This is RoboSpeaker
(Speaking...)

Enter what you want to speak:
> thankyou
Thank you for using RoboSpeaker

--------------------------------

[ FEATURES ]
✔ Continuous input (no restart required)
✔ Simple terminal interface
✔ Fast text-to-speech
